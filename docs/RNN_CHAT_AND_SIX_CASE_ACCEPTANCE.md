# RNN/LLM chat and boot acceptance

The chat client is a userspace adapter for a separately installed OpenAI-compatible model server; it is not a trained LLM and bundles no weights. It bounds chat history, rejects plaintext remote endpoints, and never executes model output. The existing RNN remains a research-scale character model.

The six-case matrix is Live/Installer/Recovery × BIOS/UEFI. All cases remain NOT_RUN until actual production ISO logs prove a CPL3-originated init syscall and matching nonzero PID READY event, with firmware, ISO/kernel hashes and logs. Live must start Aurora; Installer must complete/reboot/boot the installed OS; Recovery must perform a real operation. Genuine AP-backed SMP is separate.
